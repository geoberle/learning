One token at a time

Your first win: explain what information is available when an LLM generates its next token. This is the starting point for understanding an inference server.

Text becomes numbers

A large language model (LLM) is a model used to process and generate language. For text generation, a prompt is the starting input. A tokenizer converts text into a sequence of numbered units called tokens. A token can represent a word, part of a word, or punctuation; token boundaries depend on the tokenizer. The model works with numbers, not printed letters. Source: Hugging Face’s tokenizer lesson.

Choose, append, repeat

In the basic generation loop, the model estimates probabilities for the next token using the prompt and tokens generated so far. A selection rule chooses one token, which is appended to the sequence. The next step uses that extended sequence. Generation stops at a stopping condition, such as an end token or a length limit. Source: text generation.

The rule might choose the most likely token, or sample according to probabilities. So the same prompt need not always produce the same continuation. Source: generation strategies.

A tiny worked example

This is an invented tokenization and continuation, not a real model run. Each bracket holds one token; spaces inside brackets belong to that token.

  1. Start with [The][ cat].
  2. Choose [ sat]. The sequence is now [The][ cat][ sat].
  3. Choose [ down] using that extended sequence.

When choosing [ down], the previously generated [ sat] is part of the available context. The future continuation has not yet been chosen. “Context” here means the sequence available for this prediction; we’ll learn later how a server reuses computation.

Try it before revealing

For this invented example, start with [Please][ bring]. The first generated token is [ tea]. Say the complete sequence available for the next prediction.

Check your answer

[Please][ bring][ tea]. Include both the original prompt and the generated token. If you omitted either, trace the append step once more.

Now suppose the next token is [.]. How many tokens were generated, and how many are in the whole sequence?

Check your count

Two generated tokens; four total tokens. The two prompt tokens were already present.
