Starter glossary

LLM
Large language model; a model used to process and generate language.
Prompt
The starting input for generation.
Token
A numbered unit in the model’s vocabulary; it may represent part of a word, a word, punctuation, or a special marker.
Tokenizer
Converts text into token IDs and converts output IDs back to text.
Context
Here, the sequence available for the next prediction: prompt plus generated tokens so far.
Next-token generation
Estimate probabilities, select a token, append it, and repeat until a stopping condition is met.
Prefill
Processes prompt tokens and initializes cached state. Its output supports selecting the first generated token.
Decode
Processes the latest selected token using cached earlier state to predict the next token.
KV cache
Reusable attention results for processed positions; its internal structure is a later topic.
Time to first token (TTFT)
Time until the first output token, including prefill and other overhead within the measurement boundary.
Inter-token latency
The time between successive output tokens.

Token counts and word counts are different. An example’s token boundaries are illustrative unless a specific tokenizer has been used.
